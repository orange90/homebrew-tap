# homebrew-tap

Homebrew formulas maintained by [@orange90](https://github.com/orange90).

## Install

```bash
brew tap orange90/tap
brew install mimo-tui
```

Or in one shot:

```bash
brew install orange90/tap/mimo-tui
```

## Formulas

| Formula | Description |
|---------|-------------|
| [`mimo-tui`](Formula/mimo-tui.rb) | Feature-rich terminal UI for Xiaomi MiMo — reasoning traces, TTS audio, multimodal input, agent loop, MCP. ([PyPI](https://pypi.org/project/mimo-tui/) · [GitHub](https://github.com/orange90/mimo-tui)) |

## Upgrade

```bash
brew update
brew upgrade mimo-tui
```

## Uninstall

```bash
brew uninstall mimo-tui
brew untap orange90/tap
```
